Interfaces gráficas com Tkinter — Teoria

1. Tkinter

Tkinter faz parte da biblioteca padrão e permite construir interfaces desktop simples orientadas a eventos.

import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("Primeira janela")
root.geometry("420x220")

label = ttk.Label(root, text="Olá, Tkinter!")
label.pack(pady=40)

root.mainloop()

2. Eventos

def salvar():

pack, grid e place. Para formulários, grid costuma oferecer melhor controle.
