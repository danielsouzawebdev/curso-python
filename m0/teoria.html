Ambiente e primeiros passos — Teoria

1. O que é Python?

Python é uma linguagem de alto nível, multiparadigma e com grande biblioteca padrão. É usada em automação, web, ciência de dados, IA, testes, scripts, aplicações desktop e infraestrutura.

2. Versão do curso

O curso usa Python 3.15 como referência. O núcleo evita recursos exclusivos dessa versão para preservar compatibilidade conceitual.

3. Instalação

No Windows, instale a versão 64-bit do Python e confirme:

python --version
py --version
pip --version

4. REPL x script

REPL é o console interativo; um script é um arquivo .py executado pelo interpretador.

print("Olá, Python!")

5. VS Code

Instale a extensão oficial Python, selecione o interpretador correto e use terminal integrado.

Erro comum: ter várias versões do Python e o VS Code usar um interpretador diferente do terminal.
