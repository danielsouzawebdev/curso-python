Fundamentos da linguagem — Teoria

1. Variáveis e tipos

nome = "Ana"
idade = 17
altura = 1.68
ativo = True

print(type(nome), type(idade), type(altura), type(ativo))

2. Tipagem dinâmica

Python associa tipos a objetos, não a nomes de variável de forma fixa. Isso não significa ausência de tipos.

3. Entrada

nome = input("Nome: ")
idade = int(input("Idade: "))
print(f"{nome} tem {idade} anos.")

4. Operadores

Aritméticos, comparação, lógicos, identidade e pertinência.

a = 10
b = 3
print(a + b, a - b, a * b, a / b, a // b, a % b, a ** b)
print(a > b, a == b)

5. Strings

Indexação, slicing, métodos e f-strings.

texto = "Programação em Python"
print(texto[0])
print(texto[0:11])
print(texto.lower())
print(texto.replace("Python", "C#"))
Prática profissional: converta e valide entradas. input() sempre retorna string.
