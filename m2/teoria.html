Decisão e repetição — Teoria

1. if/elif/else

nota = 78
if nota >= 90:
    conceito = "A"
elif nota >= 70:
    conceito = "B"
else:
    conceito = "C"
print(conceito)

2. Operadores lógicos

idade = 20
tem_documento = True
if idade >= 18 and tem_documento:
    print("Entrada permitida")

3. match

comando = "listar"
match comando:
    case "listar":
        print("Listando...")
    case "sair":
        print("Encerrando...")
    case _:
        print("Comando desconhecido")

4. for e range

for numero in range(1, 6):
    print(numero)

5. while

senha = ""
while senha != "1234":
    senha = input("Senha: ")
print("Acesso liberado")

6. break e continue

Use com intenção clara; laços difíceis de entender indicam que o algoritmo pode precisar ser reorganizado.
