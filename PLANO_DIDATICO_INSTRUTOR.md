# Plano didático — Python

## Princípio
O aluno deve prever o comportamento do código antes de executar, testar hipóteses, ler mensagens de erro e justificar escolhas.

## Ambiente
Python 3.15 + VS Code. Os exemplos centrais evitam dependência desnecessária de recursos exclusivos da versão.

## Avaliação
Priorize problemas novos, diagnóstico e defesa individual do código.

## Projeto final
Sistema de chamados desktop com POO, SQLite, Tkinter, exportação, logs, testes e documentação.
