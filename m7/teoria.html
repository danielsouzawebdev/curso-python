Ambientes, pacotes e dependências — Teoria

1. Ambiente virtual

python -m venv .venv
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
# cmd
.venv\Scripts\activate.bat

2. pip

python -m pip install requests
python -m pip list
python -m pip freeze > requirements.txt

3. Por que usar python -m pip?

Ajuda a garantir que o pip executado pertence ao mesmo interpretador Python selecionado.

4. Estrutura

meu_projeto/
├── .venv/
├── src/
│   └── app/
│       ├── __init__.py
│       └── servicos.py
├── tests/
├── README.md
└── pyproject.toml

5. PyPI e dependências

Pacotes externos trazem manutenção e risco. Instale apenas o necessário e registre versões quando reprodutibilidade importar.

Git: normalmente não versione .venv/.
