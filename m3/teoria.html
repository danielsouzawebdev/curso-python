Coleções e estruturas de dados — Teoria

1. Listas

nomes = ["Ana", "Bruno", "Carla"]
nomes.append("Diego")
nomes.sort()
for nome in nomes:
    print(nome)

2. Tuplas

São sequências imutáveis. Úteis para valores que não devem ser alterados.

3. Dicionários

aluno = {"nome": "Ana", "nota": 8.5}
print(aluno["nome"])
aluno["aprovado"] = aluno["nota"] >= 7

4. Sets

a = {"Python", "Git", "SQL"}
b = {"Python", "HTML"}
print(a & b)
print(a | b)

5. Comprehensions

quadrados = [n * n for n in range(1, 11)]
pares = [n for n in range(1, 21) if n % 2 == 0]
