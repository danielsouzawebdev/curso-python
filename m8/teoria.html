Banco de dados com Python — Teoria

1. SQLite

SQLite é embutido e não exige servidor separado, ideal para aprender persistência relacional.

import sqlite3

with sqlite3.connect("app.db") as con:
    con.execute("""
        CREATE TABLE IF NOT EXISTS clientes (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nome TEXT NOT NULL,
            email TEXT NOT NULL UNIQUE
        )
    """)

2. INSERT parametrizado

with sqlite3.connect("app.db") as con:
    con.execute(
        "INSERT INTO clientes (nome, email) VALUES (?, ?)",
        ("Ana", "ana@exemplo.com")
    )

3. SELECT

with sqlite3.connect("app.db") as con:
    linhas = con.execute("SELECT id, nome, email FROM clientes").fetchall()
    for linha in linhas:
        print(linha)

4. Transações

Operações que precisam acontecer juntas devem estar na mesma transação.

5. SQL Injection

Nunca construa SQL concatenando entrada do usuário. Use placeholders.

6. MySQL como aprofundamento

O mesmo modelo conceitual se aplica, mas exige driver e servidor. Use conexão configurável e não grave senha em repositório.
