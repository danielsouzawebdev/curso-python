Testes, depuração e qualidade — Teoria

1. Debug

Use breakpoints, inspeção de variáveis, pilha de chamadas e execução passo a passo. print() ajuda, mas não substitui um depurador em problemas complexos.

2. Logging

import logging

logging.basicConfig(level=logging.INFO)
logging.info("Aplicação iniciada")
logging.warning("Estoque baixo")

3. unittest

import unittest

def somar(a, b):
    return a + b

class TestSomar(unittest.TestCase):
    def test_soma_positivos(self):
        self.assertEqual(somar(2, 3), 5)

if __name__ == "__main__":
    unittest.main()

4. pytest

def test_soma_positivos():
    assert somar(2, 3) == 5

5. Formatação e lint

Ferramentas como Ruff e Black podem automatizar parte da consistência. Elas não substituem design e legibilidade.

6. Refatoração

Refatorar altera estrutura interna mantendo comportamento observável. Faça em passos pequenos e protegidos por testes.
