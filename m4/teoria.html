Funções e organização — Teoria

1. Funções

def calcular_media(notas: list[float]) -> float:
    return sum(notas) / len(notas)

print(calcular_media([8.0, 7.5, 9.0]))

2. Parâmetros

def saudacao(nome: str, mensagem: str = "Olá") -> str:
    return f"{mensagem}, {nome}!"

print(saudacao("Ana"))
print(saudacao("Ana", mensagem="Bem-vinda"))

3. Escopo

Prefira retorno de valores a manipulação excessiva de globais.

4. Type hints

Anotações melhoram documentação e ferramentas, mas não transformam Python em linguagem estaticamente tipada em runtime.

5. Módulos
