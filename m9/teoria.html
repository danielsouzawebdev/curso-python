APIs e automação — Teoria

1. HTTP e APIs

Uma API web frequentemente expõe recursos via HTTP e representa dados em JSON.

2. requests

import requests

resposta = requests.get(
    "https://jsonplaceholder.typicode.com/users",
    timeout=10
)
resposta.raise_for_status()
usuarios = resposta.json()
for u in usuarios:
    print(u["name"])

3. Timeout e erros

import requests

try:
    r = requests.get("https://example.com", timeout=5)
    r.raise_for_status()
except requests.RequestException as erro:
    print(f"Falha de rede: {erro}")

4. Automação de arquivos

from pathlib import Path

for arquivo in Path("entrada").glob("*.txt"):
    novo = arquivo.with_name(arquivo.stem.lower() + arquivo.suffix)
    arquivo.rename(novo)

5. Segurança

Não armazene tokens de API diretamente no código. Use variáveis de ambiente/configuração fora do repositório.
